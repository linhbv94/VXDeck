- Bản phát hành đầu tiên của VXDeck (v1.0.0) — Bảng sưu tập ứng dụng nổi (Transient App Launcher) siêu nhẹ cho macOS.
- Phân nhóm ứng dụng trực quan theo các Collection linh hoạt (Thêm, Xóa, Đổi tên, Thu gọn/Mở rộng).
- Hỗ trợ kéo thả sắp xếp ứng dụng (Drag & Drop Reordering) với thanh chỉ báo vị trí chèn mượt mà.
- Kích hoạt ứng dụng 1-chạm (1-Click Launch) qua native NSWorkspace API, tự động ẩn popup gọn gàng.
- Điều chỉnh độ rộng cửa sổ linh hoạt theo ý muốn (Dynamic Resizable Width) với bố cục cột tự co giãn thích ứng.

- Tối ưu hóa sâu cho macOS 14+ và macOS 26 (macOS SDK 27.0 baseline).
